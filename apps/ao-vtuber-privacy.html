プライバシーポリシー

対象アプリ：AI VTuber Ao ／ 最終更新日：2026年10月25日

1. はじめに

本プライバシーポリシーは、Iruk（以下「開発者」）が運用する YouTube 配信ツール「AI VTuber Ao」（以下「本ツール」）における 情報の取り扱いについて説明するものです。本ツールは開発者本人が自身の配信のためだけに、自身の PC 上で使用するものであり、一般の利用者には提供していません。

2. Google アカウントとの連携について

本ツールは、Google の OAuth 認証を使い、開発者本人の YouTube チャンネルだけにアクセスします。他の方のアカウントやチャンネルにアクセスすることはありません。利用する権限（スコープ）と用途は次のとおりです。

  • YouTube の管理（youtube.force-ssl）：ライブ配信枠の作成、配信タイトル等の設定、ショート動画の非公開アップロードに使用します。
  • YouTube Analytics の閲覧（yt-analytics.readonly）：開発者本人のチャンネルの視聴数などの分析データを読み取り、配信内容の改善に使用します。

これら以外の目的で Google ユーザーデータを使用することはありません。

3. データの保存場所

認証で得たアクセストークン、および YouTube API から取得したデータは、開発者本人の PC 内にのみ保存されます。開発者や第三者のサーバーへ送信・保管することはありません。

4. 第三者提供・販売・広告利用について

Google ユーザーデータを第三者へ提供・共有・販売することはありません。また、広告の表示やターゲティング、トラッキングの目的で使用することもありません。

5. 許可の取り消し

本ツールに与えた許可は、Google アカウントの設定（サードパーティのアクセス管理）からいつでも取り消せます。取り消し後は、本ツールから YouTube へアクセスできなくなります。PC 内に保存したトークンは削除することで完全に破棄できます。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

7. プライバシーポリシーの変更

本ポリシーは、法令の変更や本ツールの機能追加に伴い、予告なく変更されることがあります。変更後の内容は本ページに掲載した時点で効力を生じます。
